# CyberNexus AI · Cyborg Landing Page

A fictional cybernetics product site featuring a robot showcase, technology timeline, and demo contact interaction.

[Quick start](#quick-start) · [Upstream project](https://github.com/shivakumarbanavath/cyborg-themed-landing-page)

## Quick start

```bash
python3 -m http.server 8000
```

Open [localhost:8000](http://localhost:8000).

[`index.html`](index.html) contains the page and [`script.js`](script.js) handles animated interactions.
